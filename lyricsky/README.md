# Lyrics Sky (Fabric, Minecraft 26.3)

Build:   gradle build        (Gradle 9.x + JDK 25)  ->  build/libs/lyricsky-0.1.0.jar
Keys:    K = menu, P = play/pause (also starts the lyric clock for YouTube songs), H = recenter lyrics

Local music: put "Artist - Title.mp3" (or .wav) into .minecraft/lyricsky/music
YouTube:     Settings > Audio & YouTube > paste your Google OAuth client ID/secret, then YouTube tab > Link.
             Create credentials at console.cloud.google.com: enable "YouTube Data API v3",
             create an OAuth client of type "TVs and Limited Input devices".
